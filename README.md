# Python Weather API Client

## Overview
This project demonstrates API integration using Python. It connects to a public weather API and retrieves real-time weather data based on user input.

## Project Structure
- main.py – Core application logic
- config.py – API configuration settings
- requirements.txt – External dependencies
- .gitignore – Ignored files configuration

## Features
- REST API integration
- HTTP GET requests
- JSON response parsing
- Basic error handling
- Modular code structure

## Technologies Used
- Python
- requests library
- REST API

## Learning Outcomes
- Understanding API communication
- Working with HTTP requests
- Parsing JSON data
- Writing modular and structured Python code
